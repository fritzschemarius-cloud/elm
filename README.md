# Lernwerkstatt – Einrichtung

1. GitHub-Konto anlegen (github.com). Der Benutzername steckt später in der Adresse.
2. Neues Repository anlegen mit dem Namen `<benutzername>.github.io`, öffentlich.
3. Diese ZIP-Datei entpacken und den INHALT des Ordners per „Add file → Upload files“ ins Repository ziehen.
   Prüfen, ob `.pages.yml` mit hochgeladen wurde (versteckte Datei). Falls nicht:
   „Add file → Create new file“, Name `.pages.yml`, Inhalt aus der entpackten Datei hineinkopieren.
4. Repository → Settings → Pages → „Deploy from a branch“, Branch `main`, Ordner `/ (root)`, Save.
   Nach 1–2 Minuten läuft die Seite unter https://<benutzername>.github.io
5. Bearbeiten: https://app.pagescms.org öffnen, mit GitHub anmelden, Repository auswählen.
   Unter „Aufgaben“ neue Aufgabe anlegen. Nach dem Speichern ist sie nach ca. 1 Minute online.
6. QR-Codes: https://<benutzername>.github.io/qr/ öffnen und drucken.

Adressen: Das Feld „Adresse für den QR-Code“ bestimmt die URL, z. B. /drehtisch/Aufgabe1
→ https://<benutzername>.github.io/drehtisch/Aufgabe1

Videos: MP4, vorher komprimieren (HandBrake, Preset „Fast 720p30“), Ziel unter 25 MB.
